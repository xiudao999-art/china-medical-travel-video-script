# 深化迭代的评审标准

先单独判断事实、角色、课程和任务是否有实质错误：虚构真实身份或案例、擅自扩展服务、用沉默/国籍代替本人回应、诊断或治疗建议、未完成明确要求的形式或时长。存在实质错误时，不能仅以总分判为完成。

六维各1–5分，每项引用文稿证据：

1. 开头与受众：目标观众有继续看的理由，后文兑现。
2. 具体内容与推进：有用信息或情节完整，有具体动作与结果，不把说明稿强制变成故事。
3. 英语与节奏：自然可说，适合形式，语言有温度，能在时长内理解。
4. 课程与自主权：适用的课程原则落实；回应这个人的需要而非僵化套SPARK；可靠、尊重、关怀与贡献有证据。
5. 服务价值与下一步：可理解为什么需要帮助，下一步合适、容易执行，不靠压力或夸大。
6. 记忆点与整体：有可记住的细节/观点，无空泛重复或强行转题。

1=严重失败；2=明显缺陷；3=可用但有突出问题；4=完成得好，只有小问题；5=有具体证据的优秀表现。不因出现课程关键词就加分；不要求每条稿包含全部课程原则。评分是编辑判断，不是人类受众调查或转化效果。

比较时隐藏版本顺序，逐题判断哪份更好并引用理由；注意新增规则是否提升一题却伤害另一题。整组观察人物、开场、叙事形式和结尾的多样性，但不为追求差异而违反原简报。

本轮完成证据：逐项课程对照；每次技能修订有实际稿件/原始资料依据；整组没有严重问题；每个题目达到至少25/30且单项不低于4，或明确继续修复其不足；新题没有退步；最后两份独立评审对剩余问题均无应立即修复的实质缺陷。保留主观分歧，不隐瞒未过项。

“最优”按可验证的文本质量持续争取：比较并保留更好的版本，避免机械凑满分。不凭无限生成或自己给高分宣称绝对最优。确有未过题目时继续修复和复测；全部完成后记录已知的风格小差异及真实观众效果尚未测量的范围。
