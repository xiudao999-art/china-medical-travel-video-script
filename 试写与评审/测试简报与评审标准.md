# 本轮试写简报与预先确定的评审标准

## 固定主测试

目标：为考虑来中国接受医疗服务的国际访客，写一篇能建立对陪诊陪游人员信任的英文内容营销口播稿。

- 形式：陪诊人员第一人称对镜头讲述，60–90 秒；英文标题与完整口播正文，中文制作备注。
- 主题：候诊时访客沉默了，陪诊人员如何观察、回应和建立信任。
- 声音：温暖、真实、自然，观众是潜在访客，不是工作人员培训班。
- 已知事实：服务角色为陪诊和陪游。没有提供品牌、城市、医院合作、价格、资质或真实患者故事。
- 情景身份：可以示意性角色扮演或明确假设，不能冒充亲历故事、客户证言。
- 课程依据：完整课程中 24:13–28:02 的可观察可靠性、尊重与倾听；GC-3-SIlence.pdf 第 5–14 页的 SPARK 和第 15–16 页的患者反馈、停顿练习。
- 主测试的表现要求：让观众看见一次有意义的停顿和一次回应对方具体需要的动作。其余脚本不强制照搬这个场景。

## 独立评审

评审者得到任务简报、原始课程资料、匿名文稿和以下标准，不得到作者的预期得分或修订结论。后续比较尽量隐藏版本顺序。每个分数必须引用具体文字说明理由；主观评分不能当作实际播放或转化数据。

先检查不能靠总分抵消的问题：捏造真实案例或业务能力、未经支持的医疗结果、文化刻板印象、把沉默当作同意、明显未完成用户要求。发现问题先修正，再判断写作优劣。

各维度 1–5 分：1 为严重失败，2 为明显缺陷，3 为可用但有突出问题，4 为完成得好且只有小问题，5 为该项有清楚的优秀证据。

| 维度 | 需要观察的证据 |
| --- | --- |
| 开头与受众相关性 | 首句让潜在访客知道与自己有什么关系，后文兑现开头承诺，不用恐惧或空泛抒情吸引注意。 |
| 具体性与故事推进 | 有一个可想象的场景；观察、对方回应、行动、变化之间有因果关系，非泛泛服务清单。 |
| 英语口语与节奏 | 台词自然且可朗读，称谓和人称一致，词数与停顿相容，不像说明书或课程摘要。 |
| 课程忠实度与人的自主权 | 不猜测沉默含义；回应此人的话，尊重时间与选择；信任有行动证据，不靠口号。 |
| 服务价值与商业下一步 | 看得出陪诊人员具体帮了什么；邀请与主题相关、可回答、不过度索取健康隐私。 |
| 记忆点与整体完成度 | 有能复述的细节或观点，结尾有回响，删去冗余和硬接的陪游桥段。 |

通过参考线：无严重问题、总分至少 25/30，且任一项不低于 4 分。分数用于定位和比较，不为了过线机械加规则。

## 迭代方式与停止条件

保留旧技能及其初稿。每轮记录“文稿中的具体问题 → 对技能的局部修订 → 用同一简报重新生成的稿件 → 独立评审”。写作者不接收上一轮成稿或评审结论，避免把一次人工润色误报为技能改进。

最终用两个新简报检查：一篇来华行程中的陪游选择，一篇医疗沟通角色解释。它们不沿用候诊场景、号码牌或沉默开头。检查场景与措辞是否多样、任务是否完成、事实和角色边界是否稳定。

最多进行三轮有证据的技能修订。达到参考线且新简报无严重退步即可结束；如果连续两轮无实质提升或达到轮数上限，保存更好版本并报告仍存在的问题。不得宣称达到未经验证的营销效果。
