# 技能修订记录

## 本轮开始时的依据

按用户要求，使用两份原始课程和 Skill Creator，以“先写一篇，再检验，再修技能”的方式改善现有技能。测试简报与评分标准在看到初稿前写定。旧技能已保存在 `skill-baseline/`。

课程审查发现：原技能对 SPARK 的 Add 和 Relate 转译较窄，偏重流程和礼貌问句；对个人回应、日常交流、根据对方实际回答继续的强调不足。陪游范例也过度集中于医院外的休息与茶歇，缺少对兴趣和生活细节的表达。课程第15–16页的体验反馈及停顿练习此前没有完整进入质量检查。

## 第1轮修订

| 观察到的问题 | 修改技能的位置与做法 | 希望再试写时观察到什么 |
| --- | --- | --- |
| 初稿只说“带回消息”，没有交代结果 | 主文件与SOP要求展示已核对的具体答案，或如实说明未知及下一步。假设结果保持假设身份。 | 服务动作真正完成，而非只声明自己可靠。 |
| “Now I have something specific to help with”像培训 | 英语指南与SOP区分对访客说话和讲解工作人员内部思路。 | 叙述更自然，情节能自己体现原则。 |
| 硬接陪游、结尾抽象 | 允许单稿集中在一个场景；下一步与该场景呼应。 | 少一次转题，保留清晰记忆点。 |
| Add和Relate缺少人情味 | 补充小幅个人回应、已表达的情绪与回应替换测试。 | 自然回应此人，不是通用“我理解”或权限问句。 |
| 陪游缺少独立题材 | 明确预约前、家属空闲时等场景；用兴趣、菜单、街区生活等细节体现帮助。 | 新选题能表现陪游的内容，不复制候诊模板。 |
| 单稿检查不能证明技能有效 | 新增评测参考文件；新写作者只看技能和固定简报，不看初稿与评分；用另外两个题目检查。 | 能区分技能改善与手工润色一个答案。 |

修改在项目 `skills/china-medical-travel-video-script/` 中进行；完成验证后同步到已安装的同名技能。没有改动用户提供的原始课程资料。

## 本轮结果

新写作者使用修改后的技能和固定简报，未阅读初稿或评语，生成 `候选A.md`。同一位匿名对比评审给旧稿23/30、新稿27/30；两个新题完成简报且无严重退步。详细证据、分数差异及剩余问题见 `质量报告.md`。最终正文直接采用通过评审的候选A，没有再用未经复核的人工改写替换它。
